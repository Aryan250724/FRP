Proactive Carbon Intelligence: ML-Based Emission Monitoring and Anomaly Detection

A machine learning–driven framework for analyzing industrial power plant operations, estimating carbon emissions, and detecting abnormal emission behavior using predictive analytics and anomaly detection.

Overview

Industrial facilities are major contributors to global greenhouse gas emissions. Traditional monitoring systems often identify inefficiencies only after excessive emissions occur.

This project develops a predictive analytics system that analyzes environmental conditions affecting power generation and estimates expected carbon emissions. The system then identifies abnormal emission patterns using anomaly detection techniques.

The final solution integrates machine learning models with an interactive dashboard built using Streamlit, enabling users to explore system behavior and generate emission predictions in real time.

Project Objectives

 -Predict power output of a power plant based on environmental conditions.

 -Estimate CO₂ emissions using power output and emission factors.

 -Detect abnormal emission behavior using machine learning.

 -Provide an interactive monitoring dashboard for visualization and analysis.
